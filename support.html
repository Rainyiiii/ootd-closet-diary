衣橱日记支持

遇到问题先看下面的常见问题；仍然无法解决，请发邮件并附上 iOS 版本、设备型号和问题截图。

备份与恢复

备份文件很大/导出需要等待

备份内嵌衣物图片，文件可能达到数十 MB。导出时会显示“整理数据 → 编码 → 写入”的进度，完成后再打开分享面板。

恢复后数据不完整

请确认选择的是本 App 导出的 JSON 备份，且文件未被截断；导入会覆盖当前数据，建议先导出当前备份。

分类锁

忘记密码

没有后门重置；密码锁数据无法恢复。可在确认不需要该分类内容后删除 App 或清除数据。

iPad/Mac 没有面容 ID

App 会自动检测：有触控 ID 用触控 ID，没有生物识别就只用密码。

附近传输

搜索不到设备

两台设备需在同一 Wi-Fi/本地网络，系统设置中允许“本地网络”。一台选发送端，另一台选接收端。

上锁分类没有传过去

默认不发送上锁内容。发送端打开“发送上锁分类”，完成面容 ID/触控 ID 或分类密码验证后再发送。

小组件

小组件通过 App Group 读取快照。先在 App 内添加衣物/记录并打开一次 App，再到主屏幕添加小组件。若仍为空，打开「我的 → 小组件同步」检查 App Group 状态。

天气

App Store 版本使用 Apple WeatherKit；天气需要 iOS 16 或更高版本。首次使用会请求定位权限，也可以手动选择城市。
